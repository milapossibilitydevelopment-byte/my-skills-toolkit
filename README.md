# My Skills Toolkit — Week 1: Voxel Edition

A GitHub Pages-ready, single-page prototype for a 12-week child skills-building program (ages 8–12).

## What is included

- Voxel/game-inspired visual design
- Week 1: All About Me
- Avatar selector
- Strength selection
- Interests selection
- Weekly quest
- Small-step goal setting
- XP and coin feedback
- Week completion badge
- Responsive mobile layout
- Print-friendly view
- Local browser saving with `localStorage`
- Optional generated visual in `assets/voxel-dashboard.png`

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, `README.md`, and the `assets` folder.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save. GitHub will provide the Pages URL.

No build system is required.

## Privacy note

The prototype stores entries only in the browser's localStorage. It does not send responses to a server.

For a production version used with children, add appropriate privacy, consent, security, accessibility, and data-retention controls before collecting identifiable information.
